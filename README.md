# 株式会社 生駒精密工業 コーポレートサイト(制作サンプル)

LuFTech ポートフォリオ⑤ コーポレートサイト(5ページ+送信完了・プライバシーポリシー)のサンプルです。
**架空の会社を想定した制作サンプルです。** 社名・住所・駅名・電話番号・数字・人名はすべて仮のものです。

HTML / CSS / バニラJS のみで作っています(ビルド不要・ライブラリなし)。
お問い合わせフォームは**フロントエンドの動きだけを再現**しており、実際には送信されません。

## ページ

| ページ | パス | 内容 |
| --- | --- | --- |
| トップ | `/` | ファーストビュー(刃先の光・火花・切り出し)・2つの入口・選ばれる3つの理由・加工事例(PCは固定して横スクロール)・数字・採用への案内・会社の基本情報 |
| アバウト | `/about/` | 代表メッセージ・強み・加工できるもの・加工事例9点(押すと詳しい表示)・設備・品質・ご依頼の流れ |
| 採用 | `/recruit/` | 白基調。社員の写真の帯・仕事・職種・1日の流れ・先輩の声・数字・教育制度・福利厚生・募集要項(タブ)・選考・FAQ |
| 企業概要 | `/company/` | 会社概要・沿革(スクロールで伸びる線)・認証・アクセス |
| お問い合わせ | `/contact/` | 取引/採用のタブ、入力の確認、図面の添付、確認画面 |
| 送信完了 | `/contact/thanks/` | 送った種類に合わせて次の行き先を案内(noindex) |
| プライバシーポリシー | `/privacy/` | 図面の取り扱い・アクセス解析を含む |

## 確認方法

ディレクトリ形式のリンク(`about/` など)を使っているため、ローカルサーバーで開いてください。

```bash
python3 -m http.server 8000
```

→ http://localhost:8000/

## 実装メモ

- **デザイン**:テーマは「削り出す、まっすぐな線」。鉄紺 `#1B2A3F`・深鉄紺 `#0F1A2A`・鋼グレーと、Noto Serif JP(見出し)/Cinzel(英字・数字)/Noto Sans JP(本文)。角は2pxまで。図面の寸法線(両端に矢印)と格子線を全体に繰り返す
- **動き**(`--motion-*` / `--ease-cut` を共通の値として定義)
  - ファーストビュー:光のラインが左から右へ走り、通った跡から写真が現れる → 火花が一度だけ散る → キャッチが切り出される。写真は最初から読み込み、演出は写真の上の幕を拭う形にしてLCPを遅らせない
  - 見出し:背景の大きな英字がスクロールに合わせて横にすべり、明朝の見出しが切り出され、寸法線が両端から中央へ伸びる
  - 加工事例(トップ):PCは画面を固定して縦スクロールで横に流す。スマホは指で横に流すカード
  - 写真の視差、数字のカウントアップ、ボタン下辺の光のライン
  - 採用:写真が少し大きい状態から戻る見出し、流れ続ける写真の帯(ホバーで停止・停止ボタンあり)、カードの順番の浮き上がり、時間の線が伸びる1日の流れ
  - `prefers-reduced-motion` ではすべて停止して最初から表示。JSが無効でも内容・フォームはすべて表示される
  - 要件ではGSAPの利用も想定していたが、固定横スクロールと火花は CSS + 少量のJS で実装し、ライブラリなしにした
- **お問い合わせフォーム**
  - 他のページの入口から `?type=business` / `?type=recruit`(採用は `&kind=visit|apply` も)で、該当するタブ・種類が選ばれた状態で開く
  - 必須の未入力・メールアドレスの形・電話番号・年齢を、入力欄の下とフォーム上部のまとめで知らせる(`aria-invalid` / `aria-describedby`)
  - 図面の添付:ドラッグ&ドロップ対応。PDF・DXF・JPEG・PNG、3ファイル・合計10MBまでを送信前に確認し、容量メーターを表示
  - 確認画面 → 「送信する」(見本)→ `/contact/thanks/` へ。見えない入力欄(ハニーポット)と二重送信の防止つき
  - **実案件では**:サーバー側の処理(例:Vercel Functions)で受け、Cloudflare Turnstile・送信回数の制限・自動返信メール・添付ファイルの非公開保存を行う
- **計測**:`window.dataLayer` に `cta_click`(どのページのどのボタンか)・`tel_click`・`form_start`・`generate_lead`(種類・添付の有無)・`scroll_depth`(採用ページ 50/75/90%)を送る。個人情報は送らない。実案件ではGTMを読み込み、GA4へ渡す
- **SEO**:ページごとの title / description、h1は各ページ1つ、加工事例は業界・材質・加工方法を文字で記載、画像の代替テキストに部品名・材質・加工方法、`LocalBusiness` / `Organization` / `BreadcrumbList` の構造化データ。架空の会社のため全ページ `noindex` にしている(実案件では canonical・sitemap.xml を設定し、送信完了ページのみ noindex)
- **地図**:見本のイラスト。実案件では Googleマップの iframe に差し替える
- **画像**:画像生成(1024px幅のJPEG)。実案件では WebP/AVIF に変換し、`srcset` で出し分ける
